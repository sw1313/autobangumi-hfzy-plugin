# 皇甫朝云杂项功能

独立于 AutoBangumi 核心和 CD2 的本地插件。设置页只有一个项目，里面的开关彼此分开。

- 下载列表播放按钮
- RSS 优先使用填入名称：非聚合订阅填写了名称时，TMDB 查询优先用这个名称；留空或聚合订阅仍使用解析出的标题
- 季度后显示过滤后的版本和视频：添加或编辑规则时，在季度后面显示「共 2 版 24 个视频」这种结果。版本按去掉集号后的发布差异计算，第 12 集的 [END]、修订版 v2、标题末尾的 .mp4.torrent 都不会单独成版；合集不会计入。视频是过滤后剩下、并且能被下载的条目
- 修复 RSS 复制按钮：用 http 打开页面时，RSS 源旁边的复制图标也能复制完整链接
- 标记命中的过滤规则：某条过滤正则命中了 RSS 标题时，这个标签会套上橘黄色框
- 打开 TMDB 成人条目：搜索剧集和电影时包含 TMDB 标记为成人的动画。同名但没有动画类型的条目仍会跳过
- 添加时以填写的季度为准：收集和订阅时，对话框里的季度优先于文件名上的季号。保存目录和重命名都用这个季度。同一条 RSS 里如果混了好几季，都会进这个季度

配置保存在 `config/hfzy.json`，不会写入主配置。
